This is an estimate, and it cannot be exact. Real token counts come from the model's own tokeniser, which differs between model families and is not something a page can carry offline. The figure here is worked out from character and word counts, and the low and high numbers above show the range you should expect. Treat it as a guide for budgeting, not as a number to invoice against.

For an exact count, the Claude API has a count_tokens endpoint that returns the real number without running the model, and every response reports its actual usage. Use those when the number has to be right.

What pushes the estimate up: code, JSON and unusual names split into more tokens than plain prose. Sinhala, Tamil and other non-Latin scripts cost considerably more tokens per character than English, so the high estimate is the one to trust for those.

Prices are the published list rates as of June 2026 and are for comparison only. They change, and they do not include prompt caching or batch discounts, both of which cut real costs substantially. Check the current rates before committing to anything.
