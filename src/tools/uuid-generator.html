UUID Generator

Made on your device. Nothing is recorded anywhere.

Which version should I use? Use v4 unless you have a reason not to — it is pure randomness and collisions are not a practical worry.

Use v7 when the value is going into a database as a primary key. It starts with a timestamp, so new rows sort next to each other and the index stays tidy. A v4 key scatters writes across the whole index, which slows a large table down. The trade-off is that a v7 reveals roughly when it was created.
