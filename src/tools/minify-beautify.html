JavaScript is not offered here, deliberately. Minifying it safely means parsing the whole language — automatic semicolons, template strings, regex literals that look like division. A find-and-replace approach silently breaks working code, which is worse than not offering it. Use a real bundler for JavaScript.

The CSS and HTML minifiers are careful ones: comments and gaps go, but text inside quotes, <pre> blocks and <script> or <style> contents are left exactly as they are.
