Morse Code Translator

Both directions, and you can hear it.

The lamp flashes along with the sound, so it still works with the volume off.

The spacing is the hard part. A dash is three times a dot, the gap inside a letter is one dot, between letters three, and between words seven. Get those wrong and a listener hears different letters entirely — which is why this plays it properly rather than just beeping evenly.

SOS is one symbol, not three letters. It is sent as a single run with no letter gaps, which is why it is written ...---... rather than ... --- .... Both are accepted here.
