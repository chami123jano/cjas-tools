Which number should I use? For embeddings, almost always cosine similarity. It measures the angle between the two vectors and ignores their length, which is what you want — a long document and a short one about the same subject should count as similar.

Dot product gives the same ranking as cosine only when both vectors are already normalised to length 1. Many embedding models do normalise, and if so the two agree; the panel above says whether yours are. If they are not, dot product quietly favours longer vectors.

Euclidean distance measures straight-line distance, so smaller means more similar — the opposite direction from the other two.
