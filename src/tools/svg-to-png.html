SVG to PNG

A sharp picture of an SVG logo or icon, at any size. Your file stays on this device.

Choose an .svg file or drag one here Or paste the SVG code below

Why SVG stays sharp at any size: it is a set of drawing instructions, not pixels. The picture is drawn fresh at exactly the size you ask for, so a 16 pixel icon and a 2048 pixel poster are both crisp.

Fonts and pictures linked from the internet inside an SVG are not loaded, for safety. If text comes out in the wrong font, convert the text to outlines in the program that made the SVG (in Inkscape: Path › Object to Path; in Illustrator: Type › Create Outlines).
