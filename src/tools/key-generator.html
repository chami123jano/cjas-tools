Secure Key Generator

Made on your device with real randomness, not a shuffled word list.

These are generated fresh in your browser using crypto.getRandomValues, the same source a password manager uses. They are not sent anywhere and nothing is stored, so closing this page loses them — copy what you need first.

A prefix like sk_live is only a label to help you spot a key in a log or a config file. It adds no security, and a real secret should never end up in a log in the first place.
