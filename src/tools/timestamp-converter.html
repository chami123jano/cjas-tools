Timestamp Converter

Both directions. Seconds, milliseconds or microseconds, worked out for you.

—seconds now —milliseconds now

—

How the unit is guessed. A Unix timestamp in seconds for any date near today is ten digits; in milliseconds it is thirteen. So the length of the number decides, and the guess is stated above so you can see what it assumed. Thirteen digits read as seconds would put you in the year 400,000 — which is exactly the bug this avoids.

Second 0 is 1 January 1970, UTC. Negative numbers are earlier than that and work fine here.
