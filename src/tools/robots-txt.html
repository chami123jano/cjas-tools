Robots.txt Generator

Build the file, then test a path against it.

CrawlerRulePath

This file is a request, not a lock. Well-behaved crawlers follow it. Anything malicious ignores it entirely, and the file is public, so listing a secret path in it tells the world exactly where to look. Protect private pages with a login, not with robots.txt.

Blocking a page does not remove it from search results. It only stops the page being read — it can still be listed from links elsewhere, with no description. To keep something out of results, let it be crawled and put noindex on the page itself.

The file belongs at the very top of the site, as example.com/robots.txt. Anywhere else and it is ignored.
