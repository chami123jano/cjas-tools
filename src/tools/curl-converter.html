cURL Converter

Paste a command from the docs, get code in your language.

Works with a command copied straight out of a browser's network tab, including backslash line breaks.

Check it before you run it. cURL has hundreds of flags and this understands the common ones: the URL, method, headers, body, basic auth, cookies, form fields and following redirects. Anything it does not recognise is listed above so you know it was dropped rather than silently ignored.
