Fill PDF Form

Type into the boxes of a fillable form, then save it. Your file stays on this device.

Choose a PDF form, or drag one here Forms with boxes you can click and type in

Which boxes are which: each box on the page has a number, and the same number is beside its place to type. Forms often give their boxes unhelpful names like "Text1", so the numbers are the thing to go by.

Sinhala and Tamil cannot go into form boxes here: the boxes use a basic font built into every PDF reader, which has only English-style letters. To write Sinhala or Tamil on a form, use Add Text to PDF, which places the words anywhere on the page.

No fillable boxes? Many forms are just a printed page saved as PDF. Use Add Text to PDF to type on those.
