Prompt Cleaner

For text pasted out of Word, a PDF or a web page.

Why this matters for a prompt. A curly quote is a different character from a straight one, so a model reading your text as code or JSON sees something subtly wrong. Zero-width characters are worse: they are completely invisible, they survive copying, and they break string comparisons and search with no visible cause.

Everything here is a plain substitution, so your actual words are untouched — only the characters around them change.
