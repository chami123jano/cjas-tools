JSON Schema Builder

Build a schema from real data, then test other data against it.

A schema from one sample is a starting point, not a specification. Fields that happen to be absent look optional, fields that happen to be null get no type, and a number that happens to be whole looks like an integer. Read it through before using it as an API contract.

The checker here covers types, required fields, enums, array items and nested objects — enough to catch real mistakes. It is not a full JSON Schema implementation, so it does not do $ref, allOf or pattern matching.
