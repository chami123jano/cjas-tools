Chat Transcript Converter

Between a pasted conversation and the shape an API wants.

Roles are guessed from the names. Anything that looks like a person — you, me, user, human, or a plain name — becomes user; assistant, bot, AI, GPT and Claude become assistant; system and instructions become system. Check the preview before relying on the output, because a transcript with unusual names can be read wrongly.

Consecutive turns from the same speaker are kept separate rather than merged, since merging changes what a model sees.
