Random Numbers and Dice

Real randomness from your browser, not a pattern.

—

—

This uses your browser's secure randomness, the same source a password manager uses, with a rejection step so every number in the range is equally likely. Taking a random value modulo the range size — the obvious way — makes the lower numbers slightly more common, which matters for a draw or a raffle.

Two dice do not give a flat spread. Seven comes up six times more often than two, because there are six ways to make it and one way to make two. The chart above shows that building up as you roll, which is worth seeing if you have ever felt a game was rigged.
