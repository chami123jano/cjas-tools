JWT Decoder

Decoded here on your device. The token is never sent anywhere.

This does not check the signature. Decoding a token and verifying it are different things — verifying needs the secret or public key the server signed it with, and that key should never be pasted into a web page. So treat what you see here as what the token claims, not as proof of anything.

A token is not encrypted. The payload is Base64, which anyone holding the token can read. Never put anything private in one.
