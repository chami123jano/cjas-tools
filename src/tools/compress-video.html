This takes a while in a browser: every frame is rebuilt using one processor core. A one-minute phone video can take several minutes. Lowering the size on screen (720p is plenty for phones) makes it much faster as well as smaller.

The result is MP4 (H.264), which plays on every phone, computer and TV, and on WhatsApp, Facebook and YouTube.
