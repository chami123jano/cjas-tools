Wheel Spinner

Click the wheel to spin it.

—

The spin is decided before the animation starts. The winner is drawn with your browser's secure randomness, then the wheel is turned to land on it — rather than spinning with a random speed and reading off wherever it stops. Done the other way, friction and rounding make some segments very slightly more likely.

Every option gets an equal slice, however long its text is, so a long name is not more or less likely than a short one.

Remove the winner is there for draws where each name can only win once. The tally keeps count if you are spinning repeatedly to check it feels fair.
